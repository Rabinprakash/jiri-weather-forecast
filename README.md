# jiri-weather-forecast
🌦️Weather forecasting project for Jiri, Nepal using 2010–2026 data. It predicts 30-day future temperature using XGBoost and LSTM models. XGBoost uses lag, rolling, and seasonal features, while LSTM learns time sequences. A Streamlit dashboard visualizes and compares both models. XGBoost gives more stable and accurate long-term results.
